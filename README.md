# Репетитор EWI для Windows

Настільний застосунок на Electron. Прогрес, налаштування і «Мій репертуар» зберігаються файлами в папці `Документи\Репетитор EWI`, яку можна змінити в налаштуваннях застосунку. Встановлення нової версії цієї папки не торкається.

## Структура

- `web-src/` — код сторінки: уроки, мелодії, аналіз звуку, інтерфейс.
- `build-web.py` — збирає `web-src` в `app/index.html` (для застосунку) і `web/ewi-tutor.html` (для браузера).
- `main.js` — вікно, дозволи на MIDI й мікрофон, файлове сховище, резервні копії, оновлення.
- `preload.js` — міст між сторінкою і сховищем.
- `.github/workflows/release.yml` — збирання інсталятора на GitHub.
- `setup-github.cmd` / `release.cmd` — налаштування GitHub і випуск версій одним кліком.

## Папка даних

```
Документи\Репетитор EWI\
  Дані\              progress.json, settings.json, metro.json
  Мій репертуар\     одна мелодія = один .json; сюди ж можна класти .mid
  Резервні копії\    щоденні копії папки «Дані», 14 останніх
  Записи\            збережені дублі з мікрофона
```

MIDI-файл, покладений у «Мій репертуар», при наступному відкритті цього розділу автоматично стає мелодією. Файли мелодій можна копіювати між комп'ютерами.

## Вчитель на Claude

Вчитель викликає офіційний Claude Code, встановлений на комп'ютері, і працює через твою підписку Claude (Pro або Max). Ключ API не потрібен і не використовується: застосунок навіть прибирає змінну `ANTHROPIC_API_KEY` з оточення, щоб запити не тарифікувались окремо.

1. Встанови Claude Code за інструкцією: https://docs.claude.com/en/docs/claude-code/overview
2. Запусти в терміналі `claude` і увійди обліковим записом із підпискою.
3. Відкрий у застосунку розділ «Вчитель». Якщо Claude Code встановлено не в PATH, вкажи шлях до `claude.exe` в налаштуваннях.

Запити рахуються в межах лімітів підписки, як і звичайна робота в Claude Code.

Потрібні Node.js 22 і Python 3.

```
npm install
python build-web.py
npm start
```

## Публікація версії з автооновленням

### Один раз: setup-github.cmd

Розпакуй проєкт у постійну папку, наприклад `Документи\ewi-tutor-app`, і двічі клацни `setup-github.cmd`. Скрипт:

1. встановлює Git і GitHub CLI через winget, якщо їх немає;
2. відкриває браузер для входу в GitHub: скопіюй код із вікна і підтверди вхід (якщо облікового запису немає, створи його на github.com);
3. вписує твоє ім'я GitHub у `package.json`;
4. створює публічний репозиторій `ewi-tutor` і завантажує туди проєкт;
5. надсилає тег версії, чекає, поки GitHub Actions збере інсталятор (5–10 хвилин), завантажує його і запускає встановлення.

Після встановлення портативну версію можна видалити: прогрес і репертуар лежать у `Документи\Репетитор EWI`.

### Кожна нова версія: release.cmd

Онови файли проєкту новими від Claude (крім `.git`) і двічі клацни `release.cmd`. Скрипт піднімає версію (1.2.1 → 1.2.2), збирає сторінку, комітить, надсилає тег, і GitHub публікує новий інсталятор. Для великих змін: `release.cmd minor` (1.2.x → 1.3.0).

Встановлені програми перевіряють оновлення при кожному запуску, завантажують його у фоні й пропонують перезапуститися, а перед встановленням роблять резервну копію прогресу.

## Примітки

- Інсталятор не підписаний цифровим сертифікатом, тому Windows SmartScreen при першому запуску покаже попередження: «Докладніше» → «Виконати однаково». Підпис прибирає попередження, але сертифікат платний.
- Автооновлення з приватного репозиторію потребує токена в застосунку, тому репозиторій для релізів має бути публічним.
- Збирати інсталятор на Linux чи macOS можна лише з Wine; надійніше збирати на GitHub Actions або на Windows командою `npm run dist`.
